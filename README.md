# ✍️ QA Manual Tasks

This repository contains selected assignments and practical tasks completed during my **QA Manual course**. It serves as a comprehensive record of my journey into software quality assurance.

## 📚 Topics Covered
*  **Test Documentation**: Creating professional test cases and detailed bug reports.
*  **Testing Techniques**: Practical application of equivalence partitioning and boundary value analysis.
*  **Static Testing**: Reviewing requirements and documentation to catch errors early.
*  **Testing Methodologies**: Deep dive into Black-box and White-box testing approaches.
*  **Databases**: SQL basics for data verification.
*  **Mobile Testing**: Specifics of testing on real devices and emulators.
*  **Web Technologies**: Understanding how the modern web works from a tester's perspective.
* **QA Processes**: End-to-end software development life cycle (SDLC).

## 🛠️ Tools Used
*  **Jira** (Project management & Bug tracking)
*  **Postman** (API testing basics)
*  **Browser DevTools** (Debugging & Console logs)
*  **SQL** (Database querying)
*  **TestRail** (Test management)

## 🎯 Purpose
The main goal of these tasks was to build a strong foundation in **Software Quality Assurance**. Through these exercises, I developed a methodical approach to finding defects and learned how to communicate them effectively to the development team using industry-standard tools.
